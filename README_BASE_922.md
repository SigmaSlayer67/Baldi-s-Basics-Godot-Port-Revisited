This is a (finished) branch meant only to adapt every singular script present in the project from dynamic typing to Statically typing. 
We will go trough a mayor refactor of the scripts to be adapted to the GDScript Style Guide: https://docs.godotengine.org/en/latest/tutorials/scripting/gdscript/gdscript_styleguide.html. 
This is a project for Godot engine and for Godot devs at the end of the day.
Only after every single requested refactor is done, the project will be published as an update or similar way.
